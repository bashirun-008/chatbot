# BVRIT Hyderabad Assistant (Streamlit + Claude)

A chatbot that answers questions from college circulars, exam notifications, regulations and proposals.
Retrieval is a lightweight BM25 search over the markdown files in `data/`; answers are generated by Google Gemini (free tier, no card needed). Get a key at https://aistudio.google.com/apikey

## Run locally
```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # add your API key
streamlit run app.py
```

## Deploy (Streamlit Community Cloud)
1. Push this folder to a GitHub repo.
2. share.streamlit.io -> New app -> select repo, branch, `app.py`.
3. Advanced settings -> Secrets: `GEMINI_API_KEY = "your-key"`
4. Deploy.

## Updating knowledge
Add or edit `.md` files in `data/` (start with `# Title`, split topics with `## Headings`). Commit and push; the app reloads.
